# 日落大决斗 (Sundown Showdown)

一款仿《荒野乱斗》(Brawl Stars) 风格的单人生死大逃杀（Solo Showdown）3D Web 游戏。
8名英雄在 $44 \times 44$ 的战场上进行对决，随着毒圈不断收缩，太阳从下午3点艳阳高照逐渐落入黄昏，最终进入漫天繁星的黑夜，战场路灯自动点亮。

---

## 🌟 核心技术亮点

1. **极致的「零外部资源」架构（Zero-Asset Architecture）**：
   - **0 外部 3D 模型**：全部角色与场景物体均基于 Three.js 基础几何体（Box, Cylinder, Sphere, Torus）程序化构建。
   - **0 外部图片贴图**：木箱木纹、水面解析法线、地形棋盘格、接触阴影烘焙均通过 HTML5 Canvas 运行时动态绘制。
   - **0 外部音频文件**：射击、爆炸、升级、毒圈等所有音效，均基于 Web Audio API 算法纯代码实时合成，自带 2D 距离空间立体声衰减。
2. **高端 3D 渲染与着色器（PCSS & Post-Processing）**：
   - **PCSS 接触硬化软阴影**：修改 Three.js ShaderChunk 注入泊松圆盘采样与遮挡物深度计算，阴影随距离自然发散，采样点对齐 Texel 避免镜头噪波闪烁。
   - **GTAO（真实环境光遮蔽）**：地面缝隙与模型立体层次分明。
   - **UnrealBloomPass**：路灯、大招能量就绪环、枪口与爆炸强光辉光。
   - **GradeShader（分色调色与暗角）**：Split-Tone 暗部染冷蓝而高亮保暖黄，营造电影级黄昏质感。
3. **动态昼夜流转系统（Day-to-Night Cycle）**：
   - 内置 24 小时关键帧颜色、光强插值。比赛随时间从 15:24（正午烈日）推进至 21:00（深蓝黑夜）。
   - 入夜后，场景内的路灯动态点亮，投射聚光灯并产生透视硬化软阴影。
4. **SDF 毒圈收缩系统**：
   - 基于圆角矩形 Signed Distance Field（SDF）实时计算毒雾安全边界。
   - 三层半透明动态流动毒雾着色器，出圈每秒承受递增伤害，并伴有心跳警告暗角。
5. **视线感知与行为树 AI（BotAI）**：
   - 支持草丛隐身（Line of sight 检测，进草隐蔽，射击或接近暴露）。
   - 具备 4 大决策状态：打箱发育（Loot）、索敌交战（Fight）、残血规避（Flee）、避毒撤离（Escape），带提前量预判射击。

## 🎮 操控指南

### 🖥️ 电脑端（键鼠）
- **移动**：`W` `A` `S` `D`
- **瞄准与普通攻击**：移动鼠标瞄准，点击 **鼠标左键** 射击
- **超级技能（大招）**：按住 **空格键** 或 **鼠标右键** 蓄力瞄准，松开即可发射
- **快捷键**：
  - `T`：快速切换时段（正午 / 黄金时刻 / 黄昏 / 黑夜）
  - `P`：暂停游戏
  - `M`：开关静音
- **右上角 ⚙️ 设置面板**：可随时切换人机难度（简单 / 普通 / 困难）、画质等级（低 / 中 / 高 / 极高）、调节特效与拖动时间滑块。

### 📱 移动端（触屏）
- **左半屏**：虚拟浮动移动摇杆
- **右半屏**：拖动瞄准、松开发射；轻触点击自动瞄准最近敌人
- **右下角黄色圆环**：大招充能完毕后，拖动或点击释放大招

## 🚀 运行方法

本工程为纯静态单文件应用，无需安装 Node.js、npm 或配置本地服务器。

- **直接双击** `index.html` 即可在任意现代浏览器（Chrome、Edge、Firefox、Safari）中畅玩！
- 也可通过任意静态服务器预览：
  ```bash
  npx serve .
  # 或
  python -m http.server 8080
  ```

## 🛠️ 二次开发指南

在 `index.html` 的 `<script>` 标签中：

1. **修改英雄属性与新增英雄**：
   搜索 `Bc = {`，修改 `hp`、`speed`、`reload`、`attack`（散布、子弹数、射程、伤害）等参数。
2. **修改地图尺寸与障碍物密度**：
   搜索 `Zl = class`，地图采用 $44 \times 44$ 网格，在 `generate(seed)` 中可配置墙体、木箱、水体、草丛比例。
3. **自定义着色器与光影**：
   搜索 `ul = [` 可调节昼夜流转的关键帧颜色；搜索 `GradeShader` 可微调滤镜与画面对比度。
