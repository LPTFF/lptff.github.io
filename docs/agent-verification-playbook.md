# Agent 可信验证 Playbook

本清单用于行为、数据流、采集、复杂 UI 和部署变更。它补充 `AGENTS.md` 的运行标准，不替代任务判断。

## 1. 建立基线

- [ ] 记录目标、受影响数据链、现有消费者、明确不做的范围和验收条件。
- [ ] 区分已确认事实、推断和未解决项；源码与上下文冲突时以受影响源码为准并同步上下文。
- [ ] 记录将使用的工具、运行环境、端口、代理、数据目录和启动条件。

## 2. 实施与局部契约

- [ ] 保持修改局部、可回滚；不以新增平行页面绕过现有消费者问题。
- [ ] 运行相关 fixture、单元测试、类型检查和编译。
- [ ] 对采集器验证 HTTPS/白名单、超时、响应大小、挑战页、Schema、最低条数、重复项和敏感字段。
- [ ] 模拟异常，证明失败不会覆盖最后有效数据或发布半成品。

## 3. 真实执行和产物

- [ ] 真实运行项目记录的采集/生成命令，而不只调用 parser 或 mock。
- [ ] 对每个脚本记录 `success`、`preserved`、`skipped` 或 `failed`，并记录耗时、条数、是否变化及脱敏原因。
- [ ] 验证真实产物的 Schema、最低条数、URL、重复项、批次/manifest 一致性和敏感信息。
- [ ] 不把退出码 0、HTTP 200 或 JSON 可解析单独称为业务成功。

## 4. 现有消费者和业务结果

- [ ] 使用生产构建和 `vite preview`，确认未误命中开发代理或历史远程数据。
- [ ] 打开现有业务路由，确认真实产物被 Vue 页面消费；直接打开 JSON 或独立 HTML 不计入闭环。
- [ ] 检查桌面和相关移动视口、关键交互、网络请求、控制台、图片和链接。
- [ ] 将业务阻断问题与无关外部资源噪声分开记录。

## 5. 报告与收尾

- [ ] 在被 Git 忽略的 `docs/verification-reports/` 保存报告与必要截图/机器摘要。
- [ ] 报告包含：基线、工具与启动条件、脱敏命令、产物校验、页面/网络/控制台、失败与跳过、复现步骤、剩余风险和责任。
- [ ] 明确每项证据证明什么、不能证明什么；事实链缺环时标为部分完成。
- [ ] 判断本轮失败经验是否需要进入规则、测试、checklist、playbook 或只读检查。
- [ ] 恢复不应进入 Review 的动态数据、生成声明、截图、报告和临时目录。
- [ ] 运行 `git diff --check`、`npm run iteration:report` 和 `npm run context:check`。
- [ ] 未经明确授权不提交或推送；只说“推送远程”但未指定分支时先确认目标分支。
