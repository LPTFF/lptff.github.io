# 迭代日志

这是仓库迭代的简洁演进日志。它与 `.claude/project-context.md` 互补：当前事实属于上下文文件；此文件记录了什么发生了变化、原因以及如何验证的。

## 条目格式

```md
## YYYY-MM-DD — 简短范围

- 范围：变更了什么，以及有意未改动什么。
- 证据/决策：影响未来工作的已确认事实或用户批准的决策。
- 文件：变更的重要文件，包括相关情况下的生成/派生文件。
- 验证：运行的命令及其结果；明确说明跳过的检查项。
- 未解决问题：未解决的抉择，或 `无`。
```
