# 人机协作边界

根目录 [AGENTS.md](../../AGENTS.md) 定义通用执行原则；本页只说明人的决定权和 Agent 的行动边界。

## 人负责

- 定义值得改善的结果和可接受风险；
- 判断价值取舍与证据冲突；
- 授权私人环境、对外、不可逆、交易及其他高风险动作；
- 审查确定的待提交版本，并明确批准每次提交和推送。

## Agent 负责

- 在授权范围内主动完成搜索、比较、实现、排错和真实验证；
- 区分事实、推测与未知，根据实际失败继续修复；
- 选择最小、可撤销且直接支持用户结果的行动；
- 把真实证据、失败、没有覆盖的范围和剩余风险直接交给人，不让人维护额外任务板或拼接多份报告。

## 停止边界

继续工作若必须猜测私人来源语义、扩大授权、执行不可逆动作或替人改变目标与风险取舍，就停止并提出一个精确缺口。涉及私人环境时遵循[最小授权验证](main-agent-authorized-validation.md)，功能结论遵循[真实环境验收原则](trusted-verification.md)。

## 提交与推送

提交和推送不是自动收尾。执行前必须向人展示当前确定版本、重要差异、删除项、真实验证环境与结果、失败或未知、目标分支和远程，并取得明确批准。批准后内容或目标发生变化，必须重新审查。
