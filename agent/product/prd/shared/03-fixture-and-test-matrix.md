# Fixture 与测试矩阵

| fixture | Agent A 验证目标 | Agent B 对应真实场景 |
| --- | --- | --- |
| normal | 完整导入和页面展示 | 正常登录且接口成功 |
| empty | 空组合和空交易 | 账户无持仓或无交易 |
| partial | Coverage、warning 和部分页面 | 分页/历史范围未完成 |
| stale | 过期提示和禁止伪造新鲜度 | 接口成功但时间过旧 |
| failed | 保留旧账本并显示失败 | 网络/接口错误 |
| complex | 多基金、多批次和字段差异 | 真实组合复杂度 |
| large | 性能、分页和批量去重 | 大规模账户返回 |

测试输入只使用脱敏 fixture。真实环境只产生结论和字段级摘要。
