# 00 产品简报

**来源**：PRD 第 1–6、59、69–70 节。**状态**：产品基线与长期判断。

## 定位

LPTFF Investment OS 是基于个人真实投资事实运行的本地投资决策、风险控制和策略验证系统。Chrome Extension 是事实感知器，Investment Ledger 是长期外部记忆，Investment Web App 负责风险分析、规则判断、行为识别和策略验证。

## 目标用户

个人使用者。第一阶段聚焦已登录天天基金、希望用自己的真实数据复盘投资行为的人，不面向多用户财富管理或公开交易服务。

## 要解决的问题

系统长期回答五个问题：

1. 现在发生了什么：账户、资产、持仓、交易和盈亏的真实状态。
2. 我的风险在哪里：指数、地区、资产类型、币种和重复底层暴露。
3. 现在是否需要行动：是否触发预先定义的规则。
4. 行为是否偏离系统：交易是否符合既有策略，是否出现异常行为。
5. 什么方法长期有效：哪些行为贡献收益、损失或回撤。

## 价值闭环

```text
事实 → 规则 → 行动 → 真实结果 → 统计证据 → 规则调整 → 再次执行
```

系统应让投资方法可记录、可重复执行、可量化、可验证和可修改，并逐渐减少用户手工输入与不必要的交易建议。

## 设计原则

- 默认无需操作，只在规则触发、风险越界、异常交易或数据不足时打扰。
- 自动获取可由真实数据推断的字段；严格区分 Fact、Inference、Suggestion。
- 数据最小化、Local-first：第一阶段本地处理和存储，不上传私人投资数据、不建设云账户、不做远程埋点。
- 成功不以页面数量、数据量、DAU 或打开次数衡量，而以数据可信、行为质量、风险认知和长期证据为准。

## 当前成功标准

软件越来越少要求用户输入，越来越少制造交易建议，越来越清楚用户实际承担的风险，并越来越能证明某种策略是否有效。实现状态以当前源码和验证结果为准，不能仅凭本简报判定已交付。
