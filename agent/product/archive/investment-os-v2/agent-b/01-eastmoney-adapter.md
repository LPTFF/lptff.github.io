# Eastmoney Adapter

## 目标

Adapter 不再只证明“接口读取成功”，而要向 Core 提供足以支持纪律判断的字段语义、时间范围、确认状态和 Coverage。每次仍限定一个来源能力/接口、一个场景、一个验证目标。

页面 DOM 只用于在授权环境中触发筛选和分页；业务字段优先来自页面真实发出的业务接口响应。输出给 Core 前转换为 Shared 协议，不能把站点字段、selector 或原始响应泄漏到页面层或 Agent A fixture。

## 分层

```text
授权真实页面/接口
→ Source-specific endpoint + selector
→ 字段语义、单位、时点、状态、分页和错误分类
→ Eastmoney Adapter
→ Shared Normalized Fact + Coverage + warning/unknown
→ Agent A Core
```

## 纪律判断所需来源能力

### 1. 账户与持仓

需要逐项验证，而不是假设可用：

- 持仓标识和基金代码的稳定性；
- 持有份额、可用份额及两者差异；
- 当前市值、成本字段及币种/单位；
- 总资产、净资产、可投资资产的来源和分母语义；
- 现金、余额或可用资金是否存在，是否包含待确认交易；
- 持仓快照时间、估值净值日期和接口返回时间是否不同；
- 空值、零值、冻结/待确认份额和未知资产如何表示。

若天天基金不可靠提供现金或总资产口径，必须返回 BLOCKED/unknown；不能从页面汇总数倒推并冒充来源事实。

### 2. 日净值历史

移动止损至少需要：

- 净值日期、单位净值/累计净值字段的准确语义；
- 历史区间、分页上限、停牌/非交易日和缺口；
- 最新可用日期与数据发布时间；
- 分红、拆分、再投资及复权含义；
- 同日多条、修订值和顺序稳定性；
- 基金类型是否具有可比较的同一 basis。

不能证明序列可比较时只允许输出原始标准化事实和 warning，禁止 Adapter 自行复权或选择有利序列。

### 3. 交易申请与确认

需要区分：

- 申购/赎回申请方向和提交时间；
- 申请金额、申请份额；
- 受理中、部分确认、确认成功、失败、撤销等状态；
- 确认金额、确认份额、确认净值和确认日期；
- 手续费、分红再投资及退款语义；
- sourceTransactionId 或稳定关联键；
- 当前交易与历史交易的重叠、分页和状态更新。

申请量不能 mapping 为确认量；状态无法区分时进入 unknown，并阻断 OperationReview completed。

### 4. 操作前后快照关联

Adapter 需要报告是否存在足以关联交易和持仓快照的：

- 稳定交易标识；
- 申请/确认时间；
- 持仓快照时间；
- 同一基金同时多笔交易的消歧信息；
- 待确认份额或资金的呈现方式。

若无法可靠建立因果关联，只返回时间邻近事实和 Coverage，Core 必须标记 partial/unknown；Adapter 不猜测“这次交易导致这份快照”。

## Mapping 记录要求

每个字段结论至少包含：

| 项目 | 内容 |
| --- | --- |
| Shared 字段 | Core 消费的稳定语义 |
| 来源能力/接口 | 脱敏标识，不保存原始响应 |
| 存在性 | present / absent / conditional / unknown |
| 业务语义 | 单位、正负方向、包含/排除项 |
| 时间语义 | 数据日期、确认日期、接口时间、时区 |
| Coverage | 历史区间、分页、缺口、最新日期 |
| 状态 | 申请/确认/失败等枚举 mapping |
| 风险 | Schema Drift、登录依赖、歧义 |
| 结论 | PASS / FAIL / BLOCKED |
| Required change | Adapter、Shared 或 Agent A 需改变什么 |

## 失败和 unknown 原则

- 字段缺失：明确 absent，不从其他真实敏感字段拼接猜测。
- 字段存在但语义不明：unknown，不标 PASS。
- 历史范围未完整加载：partial Coverage。
- 登录失效：authentication_required，不降级为空账户。
- Schema Drift：停止受影响 mapping，保留未受影响范围。
- 来源能力不足：BLOCKED，并指出需用户手动输入规则、其他授权来源或产品降级。

## 隐私与安全

Agent B 只输出字段级脱敏结论。禁止输出或保存基金名称、真实金额、收益、可组合识别个人的日期金额、原始 JSON/HTML、Cookie、Token、银行卡、登录状态或完整 Network Logs。不得执行申购、赎回、买卖、转账或其他账户操作。
