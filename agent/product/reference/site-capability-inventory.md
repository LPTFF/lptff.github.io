# 站点业务能力清单

> 文档版本：2026-08-30
> 文档性质：基于当前源码、路由和导航配置整理的站点事实，不描述未来规划。

## 当前产品结构

```text
个人综合信息工作台
├── 首页门户
│   ├── 热门资讯
│   ├── 吾爱破解
│   ├── 导航专区
│   ├── 豆瓣电影
│   └── 薅羊毛
├── 投资与复盘
│   ├── Investment Review（当前唯一 P0）
│   └── Contract Review（冻结的验证原型）
├── 博客与长期内容资产
│   ├── 文章、搜索、分类与归档
│   └── 职业知识、产品复盘和旧功能归档
└── 独立个人工具
    ├── 开发工具
    ├── Live2D 看板娘
    └── 快手/抖音待完善占位
```

站点没有注册、角色和云端账号体系，主要服务站点所有者，同时公开展示博客、资讯和部分工具。它不直接执行基金或合约交易，不托管资产，不保证外部链接或内容来源持续可用。

## 首页门户

首页路由为 `/`，栏目状态通过页面内部切换；`/welfare` 兼容地址会回到首页并打开福利栏目。

| 栏目 | 当前能力 | 数据与边界 |
| --- | --- | --- |
| 热门资讯 | 合并浏览资讯和吾爱破解内容并跳转原文 | 本地数据快照，不提供决策闭环 |
| 吾爱破解 | 单独浏览相关帖子并跳转来源 | 本地数据快照 |
| 导航专区 | 分类打开内外部网站，并按本机点击次数生成“常用”分组 | 点击次数只保存在当前浏览器 |
| 豆瓣电影 | 浏览电影名称、海报和评分 | 本地快照与外部详情 |
| 薅羊毛 | 浏览福利线报和 HTTPS 公共索引 | 不负责报名、资格、返利或订单追踪 |

导航专区当前明确保留基金复盘助手、合约复盘、技术博客、开发工具、Live2D，以及快手/抖音待完善入口。旧加密货币分析已退出导航。

## 博客与内容资产

博客根路由为 `/blog`，当前提供：

- 文章列表、Markdown 正文和目录；
- 全文搜索、分类、年度归档、阅读和关于页；
- 历史博客路径兼容；
- 职业知识树、产品演变记录和旧功能归档。

博客没有登录、投稿、评论、点赞、收藏或订阅能力。

## Investment Review

`/investment` 是当前唯一 P0 产品，子路由包括：

```text
/investment
├── review
├── portfolio
├── policies
├── actions
├── data
└── evidence
```

当前运行时已具备来源 Adapter、本地 IndexedDB Ledger、Coverage、投资范围、版本化规则与计划、操作/仓位/移动止损/减仓判断，以及处理后的恢复复核。

它不提供权威买卖建议或自动交易；绩效测量、归因、策略证据和 AI Review 仍未交付。启动其他完整产品前，Investment Review 必须先完成至少 3–5 个真实复盘周期，并证明减少遗漏、重复错误或完整复盘时间。详细边界见 [Investment Review 产品正文](../investment-review.md)。

## Contract Review

`/contract-review` 当前保留真实合约来源采集、本地台账、确定性历史统计、证据明细和本人规则对照，但产品状态是**冻结的验证原型**。

当前边界：

- 不提供默认杠杆、仓位、止损、止盈、盈亏比或交易数量；
- 规则未由用户逐项填写并确认时，不生成规则偏离结论；
- 计划检查只表示是否发现与本人规则的机械偏离，不表示安全或可以执行；
- 不使用回退账户权益、价格或数量补齐缺失事实；
- 冻结期间不增加新功能、新来源或新 AI 工作流。

重新启动门槛见 [Contract Review 产品正文](../contract-review.md)。

## 独立个人工具

### 开发工具

`/devtools` 当前包含文本压缩、文本转二维码和 JSON 格式化。数据在浏览器中处理，不构成云端服务。

### Live2D 看板娘

`/live2d` 用于选择和开启看板娘；启用状态与模型选择保存在本机，移动端不显示。

### 待完善占位

`/pending` 仍承接导航中的快手和抖音待完善入口。它只说明功能尚未交付，不应被理解为已经可用的采集或分析产品。

## 已归档或删除的功能

| 历史入口 | 当前处理 |
| --- | --- |
| `/message`、`/fundPilot`、`/fundPilotPlus`、`/fundPilotV1` | 重定向到基金工具演变文章；旧源码只供 Git 历史追溯 |
| `/fundHoldInfoMsg` | 页面和路由已删除，不并入 Investment Review |
| `/cryptocurrency` | 重定向到加密货币工具演变文章；旧页面源码已删除 |
| `/advanced-search`、`/newsArticle` | 重定向到信息工具演变文章 |
| `/tech-forum`、`/github-trending`、`/leetcode` | 重定向到职业工具演变文章 |
| `/interview` | 重定向到博客中的面试知识归档 |
| `/boss-zhipin` | 重定向到职业决策方向文章；真实市场能力由浏览器扩展承担 |

归档页面不再作为当前产品能力，也不应因旧源码、历史记录或数据文件仍可追溯而被写成“正式使用”。

## 当前入口总表

| 业务域 | 入口 | 状态 | 主要动作 |
| --- | --- | --- | --- |
| 首页门户 | `/` | 保留 | 切换栏目、浏览内容、访问导航 |
| 博客 | `/blog` | 保留 | 阅读、搜索、分类和归档 |
| Investment Review | `/investment` | P0 | 同步事实、纪律与执行复盘、处理和恢复复核 |
| Contract Review | `/contract-review` | 冻结原型 | 查看真实历史事实、本人规则对照和证据 |
| 开发工具 | `/devtools` | 保留 | 文本压缩、二维码、JSON 格式化 |
| Live2D | `/live2d` | 保留 | 开启和选择模型 |
| 待完善占位 | `/pending` | 未交付 | 查看占位说明 |

## 数据与状态边界

- 资讯、电影和福利主要消费仓库内静态快照；
- Investment Review 与 Contract Review 的私人事实保存在浏览器本地 Ledger；
- 导航常用次数、页面滚动位置和部分界面偏好只保存在当前设备；
- 登录态、凭据、真实私人数据和原始网络响应不进入产品文档；
- 页面存在、JSON 可读取、构建成功或一次演示不等于长期产品价值已经得到证明。
