> 文档版本：2026-08-09
> 文档性质：基于当前源码、路由和导航配置整理的业务功能说明，不描述未来规划，也不替代接口或技术设计文档。

## 1. 文档目的

本文用于说明网站当前面向用户提供的业务能力、页面入口、核心使用流程和业务边界。

本文优先回答以下问题：

- 这个网站为谁提供什么服务？
- 用户可以从哪些入口进入哪些功能？
- 各个页面解决什么问题？
- 页面之间如何形成业务闭环？
- 哪些内容是网站内部能力，哪些只是外部网站快捷入口？
- 哪些功能已经存在，哪些仍属于待开发或演示状态？

本文暂不展开以下内容：

- 前端组件实现细节；
- 爬虫脚本实现细节；
- 数据库、接口和部署架构设计；
- 安全整改、性能优化和代码缺陷分析；
- 尚未实现的产品规划。

## 2. 产品定位

### 2.1 整体定位

这是一个面向个人使用的综合信息工作台，聚合了以下几类能力：

1. **信息浏览**：查看技术资讯、吾爱破解、GitHub Trending、豆瓣电影、福利线报等内容快照。
2. **常用入口导航**：集中管理 AI、金融、娱乐、开发、工作、知识和内部功能入口。
3. **学习与求职**：阅读博客、面试知识树、项目串联资料，浏览 LeetCode 题目和招聘信息。
4. **投资信息与本地复盘基础**：既保留历史基金/加密货币策略展示，也提供 `/investment` 下的事实同步、本地 Ledger、Coverage、持仓/暴露、Policy、Action 和 Evidence 基础。
5. **外部服务跳转**：将资讯详情、招聘详情、购买页面和第三方工具作为快捷访问入口。

### 2.2 主要用户

当前源码没有建立用户注册、角色和权限体系，因此业务上主要面向两类使用者：

- **站点所有者/个人使用者**：使用导航、信息聚合、学习资料和投资分析工具。
- **公开访问者**：浏览博客、面试资料、资讯和部分公开页面。

以上用户划分是根据现有页面和交互推断的业务定位；项目当前没有通过账号体系对两类用户进行区分。

### 2.3 产品边界

网站当前是“信息展示、辅助判断和外部跳转”平台，不是以下系统：

- 不是基金或加密货币交易系统；
- 不直接执行买入、卖出或转账；
- 不托管用户资产；
- 不提供正式招聘投递闭环；
- 不提供站内评论、私信或社区互动；
- 不提供多用户协作和云端个性化配置；
- 不保证外部链接、行情 iframe 或第三方数据持续可用。

基金和加密货币页面中的“建议”“策略”“交易金额”等内容属于数据展示和个人辅助决策信息，用户仍需自行判断，不构成自动交易或专业投资承诺。

## 4. 首页门户业务

首页路由为 `/`，顶部提供五个业务栏目。栏目切换在首页内部完成，当前不是独立 URL 状态。

### 4.1 热门资讯

**入口**：首页 → 热门资讯
**实现页面**：[src/views/home/guide/index.vue](../../../src/views/home/guide/index.vue)

业务目的：将多个来源的内容合并为一个按时间排序的信息流，作为用户进入网站后的综合资讯入口。

当前展示的主要来源包括：

- 南方周末/资讯类内容；
- GitHub Trending；
- 吾爱破解。

用户可以：

- 按时间浏览内容列表；
- 查看标题、时间、来源和图片信息；
- 点击内容跳转到外部详情页；
- 在移动端使用更紧凑的内容展示方式。

业务特征：

- 内容以数据快照为主；
- 详情通常在外部网站打开；
- 首页会根据滚动位置逐步展示更多内容；
- 首页和独立页面可能使用同一类数据，但展示范围不同。

### 5.1 薅羊毛

**路由**：`/welfare`
**实现页面**：[src/views/home/welfare/index.vue](../../../src/views/home/welfare/index.vue)

业务目的：聚合多个线报、优惠和活动来源，帮助用户发现可参与的福利信息。

当前数据主要来自多个福利/线报来源的静态快照。0818 业务目标保留：由于官方内容链目前仍只有 HTTP，采集器不直接请求原站，也不降低 TLS 校验；当前通过公开的 RSSHub HTTPS 路由读取 TopHub 的“0818团 · 最新线报活动”公共索引，并逐条校验原始目标确属 `www.0818tuan.com`。页面只提供明确标为“0818团（HTTPS 公共索引）”的 HTTPS 索引入口，时间表示索引更新时间而非单条内容发布时间，不直接打开原站 HTTP 详情。独立置顶 collector 和数据文件均保留；现有数据文件是 2023 年 HTTP 历史合同，当前消费者不导入。公开 RSS 及其 RSSHub 路由实现只提供标题、链接和描述，没有显式置顶字段，因此在找到可验证的 HTTPS 置顶来源前不发布或展示推测的置顶项，也不把普通榜首当作置顶。该页面不负责活动报名、资格校验、返利结算或订单跟踪。

## 7. 投资信息与本地复盘基础

投资业务目前有两条并存但职责不同的实现：

1. `/investment` 下的 Investment OS，提供标准化事实、本地账本和局部复盘基础；
2. `/message`、`/fundPilot*` 等历史策略展示页面，主要消费运行时 JSON、提供筛选/比较/导出或外部跳转。

### 7.1 Investment OS

**根路由**：`/investment`

**实现目录**：[src/views/investment/](../../../src/views/investment/)

**领域代码**：[src/investment/](../../../src/investment/)

当前子路由：

```text
/investment
├── portfolio
├── policies
├── actions
├── data
└── evidence
```

另有 `/investment/legacy/*`，包括 dashboard、import、holding、performance、transaction 和 review 历史页面。

当前可确认的 OS 基础包括：

- 来源 Adapter/扩展同步后的部分标准化 Portfolio、Holding、Transaction、DailyPnL 和 Coverage；
- 浏览器本地 IndexedDB Ledger；
- Portfolio 和部分资产元数据/暴露聚合；
- Policy/PolicyVersion 与有限 Policy rule evaluation；
- 当前主要面向异常大额主动买入的 Behavior pattern；
- Action、Data 和 Evidence 的展示及局部状态处理。

当前限制：

- 尚无 canonical `/investment/review` 路由；legacy review 不能替代按用户问题组织的新复盘；
- 尚无明确的用户 InvestmentScope、事前 OperationPlan、计划/实际对照和按问题独立传播的判断状态；
- 当前 Policy 主要检查通用 exposure，Behavior 主要识别历史大额主动买入，均不能完整回答用户规则相对的操作异常、单基金仓位、移动止损或减仓恢复；
- 尚无申请、部分确认、撤销、操作后快照等完整执行生命周期；Action 状态变化不等于真实交易已确认或规则已恢复；
- 尚无以现金、费用、外部现金流和估值边界调和的 Absolute/TWR/MWR/XIRR；
- 尚无事前 BenchmarkVersion、Target/Benchmark 分离和可靠 Excess Return；
- 当前累计 DailyPnL 金额差不是专业组合百分比回撤；
- 尚无不可覆盖的 DecisionRecord、Process/Outcome 分离 Appraisal、Attribution、StrategyHypothesis 或可追溯 AI Review。

因此当前能力主要降低取数、归一化和查看事实的成本，尚不能完成完整基金复盘。当前差距、目标产品、本次分工和状态统一见 [Investment Review 人的产品审查](../investment-review.md)，不得把目标写成已实现。

## 11. 业务数据和状态说明

### 11.1 内容数据

当前业务内容主要有三种形态：

- **本地静态快照**：资讯、电影、福利、GitHub Trending、LeetCode 等内容随前端或数据快照发布；
- **运行时数据文件**：基金、加密货币和推荐文章页面在运行时请求 JSON；
- **远程外部内容**：详情页、搜索结果、招聘、行情和购买页面通常跳转到第三方网站。

因此页面内容是否最新，取决于对应数据快照或外部站点的更新时间；网站本身不是所有数据的原始生产者。

### 11.2 用户本地状态

当前部分用户状态保存在浏览器本地：

- 首页各栏目滚动位置；
- 面试页面当前文档页签；
- 基金列表显示数量和滚动位置；
- 导航网站点击次数和常用分组。

这些状态主要服务于当前设备上的连续浏览，不属于跨设备账户数据。

### 11.3 外部跳转

外部跳转是当前业务的重要组成部分。典型目标包括：

- 资讯原文；
- GitHub 项目；
- LeetCode 题目和答案；
- 导航专区中的外部招聘网站；
- 基金购买页面；
- 行情页面；
- 币安、TradingView、coinGlass 等第三方服务。

本站通常只负责展示入口和摘要，不负责第三方页面的内容、登录状态、交易结果或服务质量。

## 12. 当前业务状态总结

### 已形成的业务闭环

- 首页聚合 → 内容摘要 → 外部详情；
- 导航专区 → 内部功能页/外部网站；
- 博客列表 → 分类/搜索 → 文章阅读；
- 面试资料 → 文档切换 → 长文阅读；
- 基金数据 → 策略分析 → 行情查看 → 外部购买/导出；
- 加密货币数据 → 筛选分析 → 外部跳转/导出。

### 目前不完整的业务闭环

- `/loginFund` 没有确认的正式认证流程；
- `/job` 尚未形成完整的求职业务；
- `/life` 尚未形成完整的生活记录业务；
- 首页栏目切换尚未形成可直接分享的独立业务链接；
- 站内评论功能当前明确不支持。
