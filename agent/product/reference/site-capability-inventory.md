## 1. 文档目的

本文用于说明网站当前面向用户提供的业务能力、页面入口、核心使用流程和业务边界。

本文优先回答以下问题：

- 这个网站为谁提供什么服务？
- 用户可以从哪些入口进入哪些功能？
- 各个页面解决什么问题？
- 页面之间如何形成业务闭环？
- 哪些内容是网站内部能力，哪些只是外部网站快捷入口？
- 哪些功能已经存在，哪些仍属于待开发或演示状态？

本文暂不展开以下内容：

- 前端组件实现细节；
- 爬虫脚本实现细节；
- 数据库、接口和部署架构设计；
- 安全整改、性能优化和代码缺陷分析；
- 尚未实现的产品规划。

## 2. 产品定位

### 2.1 整体定位

这是一个面向个人使用的综合信息工作台，聚合了以下几类能力：

1. **信息浏览**：查看资讯、吾爱破解、豆瓣电影、福利线报等内容快照。
2. **常用入口导航**：集中管理 AI、金融、娱乐、开发、工作、知识和内部功能入口。
3. **职业资产与市场方向**：博客归档面试知识树、项目证据和旧职业功能；BOSS 真实市场能力由浏览器插件承担。
4. **投资信息与本地复盘基础**：既保留历史基金/加密货币策略展示，也提供 `/investment` 下的事实同步、本地 Ledger、Coverage、持仓/暴露、Policy、Action 和 Evidence 基础。
5. **外部服务跳转**：将资讯详情、招聘详情、购买页面和第三方工具作为快捷访问入口。

### 2.2 主要用户

当前源码没有建立用户注册、角色和权限体系，因此业务上主要面向两类使用者：

- **站点所有者/个人使用者**：使用导航、信息聚合、学习资料和投资分析工具。
- **公开访问者**：浏览博客、面试资料、资讯和部分公开页面。

以上用户划分是根据现有页面和交互推断的业务定位；项目当前没有通过账号体系对两类用户进行区分。

### 2.3 产品边界

网站当前是“信息展示、辅助判断和外部跳转”平台，不是以下系统：

- 不是基金或加密货币交易系统；
- 不直接执行买入、卖出或转账；
- 不托管用户资产；
- 不提供正式招聘投递闭环；
- 不提供站内评论、私信或社区互动；
- 不提供多用户协作和云端个性化配置；
- 不保证外部链接、行情 iframe 或第三方数据持续可用。

基金和加密货币页面中的“建议”“策略”“交易金额”等内容属于数据展示和个人辅助决策信息，用户仍需自行判断，不构成自动交易或专业投资承诺。

## 4. 首页门户业务

首页路由为 `/`，顶部提供四个业务栏目。栏目切换在首页内部完成，当前不是独立 URL 状态。

### 4.1 热门资讯

**入口**：首页 → 热门资讯
**实现页面**：[src/views/home/guide/index.vue](../../../src/views/home/guide/index.vue)

业务目的：将多个来源的内容合并为一个按时间排序的信息流，作为用户进入网站后的综合资讯入口。

当前展示的主要来源包括：

- 南方周末/资讯类内容；
- 吾爱破解。

用户可以：

- 按时间浏览内容列表；
- 查看标题、时间、来源和图片信息；
- 点击内容跳转到外部详情页；
- 在移动端使用更紧凑的内容展示方式。

业务特征：

- 内容以数据快照为主；
- 详情通常在外部网站打开；
- 首页会根据滚动位置逐步展示更多内容；
- 首页和独立页面可能使用同一类数据，但展示范围不同。

**路由**：`/welfare`
**实现页面**：[src/views/home/welfare/index.vue](../../../src/views/home/welfare/index.vue)

## 7. 投资信息与本地复盘基础

投资业务目前有两条并存但职责不同的实现：

1. `/investment` 下的 Investment OS，提供标准化事实、本地账本和局部复盘基础；
2. `/message`、`/fundPilot*` 等历史策略展示页面，主要消费运行时 JSON、提供筛选/比较/导出或外部跳转。

### 7.1 Investment OS

**根路由**：`/investment`

**实现目录**：[src/views/investment/](../../../src/views/investment/)

**领域代码**：[src/investment/](../../../src/investment/)

当前子路由：

```text
/investment
├── portfolio
├── policies
├── actions
├── data
└── evidence
```

当前可确认的 OS 基础包括：

- 来源 Adapter/扩展同步后的部分标准化 Portfolio、Holding、Transaction、DailyPnL 和 Coverage；
- 浏览器本地 IndexedDB Ledger；
- Portfolio 和部分资产元数据/暴露聚合；
- Policy/PolicyVersion 与有限 Policy rule evaluation；
- 当前主要面向异常大额主动买入的 Behavior pattern；
- Action、Data 和 Evidence 的展示及局部状态处理。

当前限制：

- P0 纪律与执行复盘（WP0-1~WP0-4）已交付：canonical `/investment/review` 路由按“需要你处理 / 等待证据或执行 / 已按计划管理”三栏组织；InvestmentScope、按问题 JudgmentResult、DecisionRecord/OperationPlan/ExecutionLink、仓位/移动止损/减仓恢复四引擎、按问题独立 Coverage 与 unknown 已实现；legacy review 不能替代它；
- 尚无以现金、费用、外部现金流和估值边界调和的 Absolute/TWR/MWR/XIRR；
- 尚无事前 BenchmarkVersion、Target/Benchmark 分离和可靠 Excess Return；
- 当前累计 DailyPnL 金额差不是专业组合百分比回撤；
- 尚无 Process/Outcome 分离 Appraisal、Attribution、StrategyHypothesis 或可追溯 AI Review（P2~P4 未启动）。

因此当前能力已能完成 P0 纪律与执行复盘（操作异常、仓位边界、移动止损、减仓进度与恢复复核），但绩效测量、归因与 AI 复盘仍为后续阶段。当前差距、目标产品、本次分工和状态统一见 [Investment Review 人的产品审查](../investment-review.md)，不得把目标写成已实现。

- 查看资金持仓数量和币种；
- 查看持仓收益率、成本价、市场价、数量和收益；
- 查看是否交易、交易类型、交易金额和交易理由；
- 查看推荐货币和合约候选货币；
- 使用表格筛选、排序和分页；
- 选择持仓货币并批量跳转或导出；
- 手动刷新数据；
- 查看自动刷新倒计时；
- 查看数据更新时间。

该页面不连接用户交易账户执行订单，也不构成托管、清算或自动跟单服务。

### 7.7 资讯文章

**路由**：`/newsArticle`
**实现页面**：[src/views/Message/NewsArticle.vue](../../../src/views/Message/NewsArticle.vue)

业务目的：展示经过筛选和推荐的财经或投资相关文章。

用户可以：

- 查看推荐理由；

- 点击标题跳转到原文。

该功能是投资信息辅助阅读，不是内容创作、评论或订阅系统。

## 10. 业务数据和状态说明

### 10.1 内容数据

当前业务内容主要有三种形态：

- **本地静态快照**：资讯、电影和福利等内容随前端发布；GitHub Trending、LeetCode、技术论坛和公开 BOSS 快照保留为冷资产，不再被生产页面消费；
- **运行时数据文件**：基金、加密货币和推荐文章页面在运行时请求 JSON；
- **远程外部内容**：详情页、搜索结果、招聘、行情和购买页面通常跳转到第三方网站。

因此页面内容是否最新，取决于对应数据快照或外部站点的更新时间；网站本身不是所有数据的原始生产者。

### 10.2 用户本地状态

当前部分用户状态保存在浏览器本地：

- 首页各栏目滚动位置；
- 基金列表显示数量和滚动位置；
- 导航网站点击次数和常用分组。

这些状态主要服务于当前设备上的连续浏览，不属于跨设备账户数据。

### 10.3 外部跳转

外部跳转是当前业务的重要组成部分。典型目标包括：

- 资讯原文；
- 博客归档文章中的历史项目与资料引用；
- 导航专区中的外部招聘网站；
- 基金购买页面；
- 行情页面；
- 币安、TradingView、coinGlass 等第三方服务。

本站通常只负责展示入口和摘要，不负责第三方页面的内容、登录状态、交易结果或服务质量。

## 11. 当前业务状态总结

### 已形成的业务闭环

- 首页聚合 → 内容摘要 → 外部详情；
- 导航专区 → 内部功能页/外部网站；
- 博客列表 → 分类/搜索 → 文章阅读；
- 职业资产 → 博客检索/归档 → 知识树或项目证据阅读；
- 基金数据 → 策略分析 → 行情查看 → 外部购买/导出；
- 加密货币数据 → 筛选分析 → 外部跳转/导出。

### 目前不完整的业务闭环

- 首页栏目切换尚未形成可直接分享的独立业务链接；
- 站内评论功能当前明确不支持。
