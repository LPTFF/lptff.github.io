# 迭代日志模板

## YYYY-MM-DD — 简短标题

- 任务基线：本轮目标、依据的已确认事实、明确不做什么和完成条件。
- 实际变更/偏离控制：改了什么；如偏离基线，说明触发证据、影响范围和确认状态。
- 文件：重要源文件、配置、生成文件和文档。
- 验证证据：运行了什么、证明了什么、跳过了什么、仍不能证明什么。
- 剩余风险/责任人：无（已核验），或列出风险、影响、责任人和后续动作。

## 维护规则

- 按时间倒序追加新条目；历史条目不回写或重新解释；
- 记录可复核的外部产物和证据，不记录 Agent 内部推理；
- 只在本轮确实发生变化时记录，不复制项目上下文全文；
- 长期仍有效的事实或风险应迁移到 `agent/context/project-context.md`。
